# مدیریت کارگاه — نرم‌افزار مدیریت کارگاه کشاورزی

> یک وب‌اپلیکیشن فارسی برای مدیریت کارگاه‌های کشاورزی.
> ثبت کار روزانه، کارگر، مواد مصرفی، درآمد، هزینه، مراحل رشد محصول
> و تولید گزارش‌های مالی.

📖 **[English version](README.md)**

---

## امکانات

- **چند کارگاه و چند سال زراعی** — مدیریت چند کارگاه، هر کدام با چند سال زراعی
- **ثبت کار روزانه** — فعالیت، تعداد کارگر، دستمزد، هزینه غذا
- **پیگیری مواد مصرفی** — ثبت کود، سم و سایر مواد برای هر فعالیت، با قیمت لحظه‌ی مصرف
- **دفتر درآمد و هزینه** — انواع درآمد و دسته‌های هزینه‌ی اختصاصی برای هر کارگاه
- **گزارش مالی** — گزارش بازه‌ی دلخواه، تفکیک ماهانه، مقایسه‌ی سال‌ها
- **خروجی CSV** — دانلود گزارش با فرمت UTF-8 (باز شدن درست در Excel)
- **آرشیو عکس** — مستندسازی مراحل رشد (خواب، هرس، گل‌دهی، برداشت و…) با عکس و یادداشت
- **پلن رایگان / حرفه‌ای** — پلن رایگان شامل ۳۰ عکس؛ پلن حرفه‌ای نامحدود با کد لایسنس
- **پشتیبان‌گیری و بازیابی** — از صفحه‌ی حساب کاربری
- **رابط کاربری راست‌چین فارسی** — با فونت وزیر
- **واکنش‌گرا** — روی دسکتاپ، تبلت و موبایل

## نصب و اجرا

### پیش‌نیاز

- Python 3.9+
- pip

### مراحل

1. کلون کردن مخزن:
   git clone https://github.com/eisaaghajani/workshop-manager.git
   cd workshop-manager

2. ساخت محیط مجازی:
   python -m venv venv

3. فعال‌سازی:
   - ویندوز: venv\Scripts\activate
   - مک / لینوکس: source venv/bin/activate

4. نصب پکیج‌ها:
   pip install -r requirements.txt

5. ساخت .env از روی نمونه:
   - ویندوز: copy .env.example .env
   - مک / لینوکس: cp .env.example .env

6. ساخت SECRET_KEY و گذاشتن در .env:
   python -c "import secrets; print(secrets.token_hex(32))"

7. اجرا:
   python app.py

برنامه روی http://localhost:5011 بالا میاد.

در اولین اجرا به /setup هدایت می‌شی تا حساب مالک رو بسازی.

---

## قدم‌های اولیه

1. http://localhost:5011 رو باز کن → به /setup هدایت می‌شی
2. حساب مالک رو بساز (نام، ایمیل اختیاری، رمز)
3. به صفحه‌ی کارگاه‌ها می‌رسی — روی «کارگاه جدید» بزن
4. یک یا چند سال زراعی اضافه کن (مثلاً 1404-1405)
5. به داشبورد هدایت می‌شی — کاشی‌ها رو کاوش کن:
   - کار روزانه — ثبت کار، کارگر، مواد
   - درآمد — ثبت فروش
   - هزینه — ثبت هزینه‌ها
   - گزارش مالی — گزارش سود و زیان
   - آرشیو — عکس و یادداشت مراحل رشد
   - مدیریت — سال‌ها، فعالیت‌ها، کودها و سموم

## پیکربندی

همه‌ی تنظیمات از طریق متغیرهای محیطی (.env) انجام می‌شه (ببین .env.example):

| متغیر           | پیش‌فرض | توضیح                                      |
| --------------- | ------- | ------------------------------------------ |
| SECRET_KEY      | خودکار  | کلید امضای session. در production عوضش کن. |
| ALLOW_REGISTER  | 0       | 1 = اجازه‌ی ثبت‌نام عمومی                  |
| BEHIND_PROXY    | 0       | 1 = پشت nginx / reverse proxy              |
| COOKIE_SECURE   | 0       | 1 = روی HTTPS                              |
| ALLOWED_ORIGINS | (خالی)  | دامنه‌های مجاز اضافی (CORS)، با کاما جدا   |
